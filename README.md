# np-reg
This is research work I have done for my Master thesis investigation novel regularization for classifiers


```/image``` ```/language``` and ```/tabular``` contain the code for the first three experiments including preparation of datasets and raw results.

```/image_finetuning``` and ```/language_finetuning``` contain the code for the transfer-learning tasks including preparation of datasets and raw results.

```/util``` contain the scripts for running data analysis and making plots.
